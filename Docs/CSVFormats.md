# CSV 格式识别与多表头

在 **设置 → CSV 格式** 选择一个普通 CSV 样本，点击“开始识别”。选择文件、切换标签或打开数据不会自动运行识别，也不会在后台替换当前 INI。STDF 和软件导出的整合 CSV 自带结构，无需识别。

识别在本地后台运行，最多读取 256 条逻辑记录 / 2 MB 文本；支持取消。建议包括 UTF-8、带 BOM 的 UTF-16 / UTF-32、GB18030（兼容 GBK），逗号、Tab、分号和竖线，以及常见 SN / XY / Site / Wafer / BIN / 产品 / 程序 / 批次字段。没有编码标记时，非 UTF-8 的文本暂按 GB18030 处理，请核对中文。

预览优先显示测项列，列名 C8 等对应原文件的第 8 列；可横向滚动查看其他列。INI 可直接编辑，再点“更新预览”。“INI 另存为”只保存文件；“采用此配置”只把候选填入设置，点击“应用分析配置并重算”后才生效。原文件始终不改写。

## 多行名称

例如：

```csv
SN,X,Y,Site,SBIN,HBIN,Wafer,Power,,Analog,
,,,,,,,Vdd,Vss,Leak,Offset
LSL,,,,,,,0,0,0,0
USL,,,,,,,3,3,1,1
Unit,,,,,,,V,V,A,V
S1,0,0,1,1,1,W1,1,2,0.1,0.2
```

对应布局：

```ini
[Layout]
TestItemRow=1
TestItemRows=1,2
TestItemColumns=
SkipRepeatedHeaders=true
LowLimitRow=3
HighLimitRow=4
UnitRow=5
TestNumberRow=0
SBinRow=0
HBinRow=0
DataStartRow=6
TestItemStartColumn=8
```

测项名称为 `Power / Vdd`、`Power / Vss`、`Analog / Leak`、`Analog / Offset`。上层空白单元格按横向合并的含义向右延续；上层本列有显式名称、下层空白时保留该名称。完全没有显式名称的列不会因继承父分组而创建虚假的测项。

`TestItemRows` 为空时使用旧版 `TestItemRow`。`TestItemColumns` 为空时，从 `TestItemStartColumn` 开始读取；有结果、时间等非测量列穿插时，可用 `TestItemColumns=8,9,12` 指定需要的列。已映射的身份列不作为测项。

## 重复表头与换行

`SkipRepeatedHeaders=true` 默认跳过与首组相同的名称行和完整定义块。仅重复名称行也可处理；定义块不完全一致时保留后续记录，避免将真实测量值误删为限值。被跳过的行不进入 Count、Eorr、复测记录或 Map，单文件加载状态会提示跳过数量。设为 `false` 可恢复逐行读取数据区的方式。

引号中的逗号、双引号转义及换行均可读取。含引号内换行时，INI 的行号表示完整 CSV 记录，等同表格软件中的一行，而非文本编辑器的物理行数；未闭合引号会报错。

## 需要确认的情况

识别是建议。无标签上下限按数值关系推测，并明确提示；没有限值时不会从最大值、最小值生成规格。没有可靠身份列时，无法自动区分无标签限值与测量数据，应手动确认数据起始行。未识别 HBIN 会影响原始 HBIN 良率；未识别 SN 时沿用自动编号规则。不会猜测无标签的 SBIN / HBIN 定义行。

同一文件内布局或限值不同的多个独立区块不自动混用配置，请拆开导入或先统一格式。文件开头超过采样范围才出现表头时，使用手动 INI。批量普通 CSV 使用当前生效的同一配置，不会逐文件自动识别。

## 首次批量打开

独立分析器中“打开文件”支持 Ctrl / Shift 多选 CSV、STDF 和压缩 STDF。多选后可调整顺序，并选择同 / 不同晶圆、按测试序号 / 名称匹配、保留首个文件阈值 / 由后续文件覆盖。选择同晶圆时首文件和每个后续文件都必须只包含一片晶圆。普通 CSV 使用当前 INI；同批 STDF 的普通 / 93k 模式只询问一次。

后续文件作为较新的记录，仍由主表的四种复测模式决定统计口径。整批成功才更新主界面；失败或取消不留下半批数据。空载时的“追加导入”也可以开始首次打开。

## 开发验证

构建主项目后，可在仓库根目录执行 `Tests/run-csv-import.ps1`。测试仅创建合成数据和隔离的配置目录，检查格式识别、多行 / 重复 / 换行表头、编码、配置另存、复测、批量失败和设置窗口取消行为。
