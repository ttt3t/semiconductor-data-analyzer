# CSV Analyzer 使用手册

**V2.0.8 · GYF**

用于半导体 CSV / STDF 测试数据的良率统计、晶圆对比、阈值模拟与报告生成。本手册随程序内置，无需联网；点击左侧目录跳转，直接阅读排版后的 Markdown 内容。

## 01 · 从这里开始

启动后先进入**产品良率与数据管理**。可以创建产品，或点击右上角**打开独立分析器**直接使用原有分析工具；独立分析器与管理窗口可分别关闭。启动参数 `--analyzer` 可跳过管理入口。以下日常分析步骤适用于独立分析器。

1. CSV 数据先在“设置”确认行列配置；标准 STDF 不需要 CSV 行列配置。
2. 点击顶部“打开文件”，选择 CSV、STDF 或压缩 STDF。STDF 会询问普通 / 93k 模式。
3. 左侧 Testitem Yield 显示测试项统计；选择一行，右侧显示该项的直方图与散点图。
4. 根据用途切换 Combine Site、复测口径，筛选并关注测试项。
5. 使用顶部 SBIN、HBIN、P/F 查看 Map；使用 BIN Table、Wafer Table 或良率预测查看汇总。
6. 使用顶部导出数据或 XLSX 报告按钮导出。

工具栏末尾的齿轮与信息图标分别打开设置、关于；当前数据与配置显示在窗口标题，处理状态位于底部。界面调整、排序、筛选与关注不会修改源文件。处理中的动画表示后台正在工作，无需连续点击。

### 产品、批次与跨温良率管理

1. 在左侧**创建产品**，填写名称，添加并排序 CP / FT 测试步骤，设置温度并勾选必测步骤。“包含 FT”会添加 FT 步骤；FT 自动计算需填写 eFuse / OTP 的 UUID Test Num，仅登记物理汇总良率时可留空。
2. 在默认解析配置页加载或编辑 INI。Pass / PartialPass HBIN、SBIN 分类沿用现有配置；可选择良品是否包含 PartialPass、同温复测采用首测还是末次整条记录。
3. **登记数据文件**可批量选择 CSV / STDF / 压缩 STDF，指定测试步骤、批次及可选晶圆号。原文件仍留在原路径。不同格式可另选行列 INI，配置以文本快照保存；STDF 可选普通 / 93k 模式。
4. CP 必须使用相同批次、相同真实晶圆号、相同 XY 对齐跨温芯片。CSV 没有晶圆列、不同温度文件名不同时，应填写统一的晶圆号；多晶圆文件需使用源数据晶圆列，不能强行覆盖成一片。
5. FT 按批次与指定测试项原文拼接的 UUID 匹配；UUID 不完整的记录独立保留。CP 与 FT 综合结果分别显示，不在缺少映射时直接合并 XY 与 UUID。
6. 上方统计口径选择**晶圆 / 批次 / 月 / 年**，统一控制明细、良率趋势和不良分类；趋势中切换 CP / FT、勾选需要的曲线，下面的数据表与曲线同步。批次 / 晶圆筛选也作用于明细与报表。分类页可打开各步骤的分类趋势。CP、FT 分别仅配置一个温度步骤时，良率明细隐藏对应的重复综合行；首页概览仍可显示该类型良率。
7. 在**良率明细**可用 Ctrl / Shift 多选行，右键已选行时保留多选；选择**打开 / 合并打开所选行**，会将所选行关联文件去重，按登记顺序、同一步骤合并到分析器；批次、月、年汇总行会包含其合并范围内的文件。跨温综合行按步骤分别打开分析窗口，不把不同温度的测试数据混为同一步骤。选择**打开所在位置**，会为每个不同的原文件分别请求一个资源管理器窗口并选中文件；即使位于同一目录也分别定位。源文件含多个晶圆或时间范围时，分析器打开该源文件的完整内容。仅指定良率且没有原文件的行会提示没有可打开的数据。旧版统计会在首次执行此操作时自动重算，以补全源文件关联；综合时间行保留较早温度步骤的关联文件。

**自动综合口径**：仅必测步骤参与综合，分母为这些步骤出现芯片的并集。任一必测步骤已明确失败，则为不良；必测步骤均完成、HBIN 有效且全部通过、多温身份可匹配，才为综合良品；其余为未完成。同一颗芯片在多个步骤失败只计一次。缺温芯片数与未完成数可能不同：缺温但已有明确失败者仍为不良。仅一个必测步骤时不需要跨温关联，缺身份记录独立计入并提示；多温综合不会据此误认它们是同一芯片。

同温跨文件复测按**登记顺序 → 文件内行号**选择整条首测或末次记录，复用 BIN Table 的原始 HBIN 判定。管理良率不会悄悄套用分析器中的临时阈值模拟方案。

### 指定良率与物理分 Bin 结果

登记文件时勾选**指定良率**，或直接点击**登记物理分 Bin 良率**（可没有原文件）。每条记录填写批次、CP 晶圆号及对应步骤，选择以下一种方式：

- 总数和良品数同时填写，由它们计算良率；此时以数量为准。
- 两者同时留空，仅填写 0–100 的良率百分比；样本数显示“–”，不虚构良品数或 HBIN 细分。

指定值作为该批次 / 晶圆 / 步骤的汇总结果，来源和说明在良率明细、文件清单及报告中保留。同一范围多次指定时沿用产品首测 / 末次口径选择。可在数据文件页**编辑登记 / 指定值**修正，也可移除登记后重新录入。移除登记不删除原文件。

**不能从两个或三个温度的百分比直接得出联合通过率。** 有指定阶段良率而缺少逐颗对应关系时，多温综合显示“无法计算”；可以在步骤中选择 **CP / FT 综合良率（物理分 Bin）**，明确登记实际测得的综合值。只有一个必测步骤时，综合与该步骤相同。指定结果缺少样本数且跨多片汇总时，不做无依据的加权合计。更改 Pass / PartialPass 口径后，旧指定值会提示口径不符，需核实并重新登记。

分类分布只来自自动解析的逐颗记录；指定汇总良率不生成虚构分类。若同一范围同时存在原始数据与指定良率，分类仅覆盖原始数据部分。

### 原文件、重算与管理报告

管理首页直接读取上次统计摘要，不自动重载大文件。原文件路径或大小、修改时间、测试配置发生变化会提示重新计算；丢失文件可在文件页重新定位。计算失败的文件不贡献部分记录，并明确标记未覆盖。计算可取消，连续重算或切换产品时仅最新任务提交结果；取消保留上次摘要。

**打开 / 合并选中文件**支持 Ctrl / Shift 多选同一测试步骤的原文件，以登记顺序自动整合并打开现有分析器。保留每个文件的解析配置、STDF 模式、登记批次与晶圆覆盖；相同晶圆保留原名作为复测，不同批次的晶圆加批次前缀区分。默认按唯一 Test Num 匹配（无法唯一匹配时改用测项名称），保留首个文件的限值；匹配仍有歧义或单位不一致时提示修正。不同温度或 CP / FT 步骤不混作复测，请分别打开；综合良率使用管理明细。无原文件的指定良率不作为原始数据合并。

管理报告导出为 XLSX，包含**晶圆良率、批次良率、良率趋势图、不良分类、分类趋势图、文件清单、流程与口径**七个工作表。选择按年 / 月后，会额外加入对应期间的良率与分类明细，趋势图同步该口径。趋势附带数值表，每页最多 10 列；报告记录来源、测试时间、未覆盖数、计算时间与筛选条件。当前勾选的良率曲线也可导出 PNG，多页时生成多张图片。

### 文件名识别、时间统计与删除

导入 STDF / 压缩 STDF 时，登记窗口会先在后台自动读取基本信息：批次来自 `MIR.LOT_ID`；晶圆号来自 `WIR.WAFER_ID`，以 `WRR.WAFER_ID` 的非空修正值为准；时间优先采用 `WIR.START_T`，其次 `MIR.START_T`，没有起始时间时再尝试晶圆 / 批次结束时间。时间按本机时区显示。读取完成后填入表格，再允许登记；读取失败的文件保留默认值并显示原因，后续正式解析仍会校验数据是否完整。

结构化 STDF 信息优先于文件名和上次登记的默认批次；缺失项沿用下面的文件名规则与系统时间兜底。一个 STDF 包含多个晶圆时不整体覆盖为一个片号；“时间来源”显示 **STDF 原始时间**，统计使用各片晶圆各次测试的时间，首测 / 末次复测选择后再归档年月。表格里显示文件的代表时间，不能把它当作所有晶圆的统一时间。逐行修改时间、重新按文件名覆盖时间，或使用统一时间按钮后，该文件改用登记时间，覆盖其全部晶圆的原始时间。

登记数据时，展开**从文件名识别片号与测试时间**。片号指定起始位置和长度，位置从 1 开始，文件名不含 `.csv` / `.stdf` / `.stdf.gz` 等扩展名，保留片号中的前导零。点击“识别空白项”只填空白字段；“重新识别并覆盖”才替换已有值，下表可随时手动修改。规则随产品保存，用于之后的批量导入。多晶圆文件不要填整文件的晶圆覆盖值。

时间长度填 0 时从文件名识别标准日期或日期时间，例如 `20261016`、`2026-10-16`、`20261016_143000`、`2026-10-16_14-30-00`；也可指定字符范围和准确格式（例如 `yyyyMMdd_HHmmss`）。遇到多个不同日期不猜测，需指定范围或手填。下表手动输入使用 `yyyy-MM-dd HH:mm:ss` 或 `yyyy-MM-dd`。新登记未识别时间时默认填入当前系统时间，并提示核对；自动填入的时间可在之后识别到真实时间时替换，手填值保留。输入**统一测试时间**后点击**应用到全部时间**可一次修改所有记录；**全部设为当前时间**提供快捷操作，之后仍可逐条修改。

上方**晶圆 / 批次 / 月 / 年**同时控制良率明细、良率趋势、不良分类及分类趋势，趋势页不再另外设置批次汇总。晶圆口径逐片显示；批次口径合计同批各晶圆；月、年按测试时间汇总。先筛选批次 / 晶圆，再汇总，各温度分别计算；有样本数时按良品数合计 ÷ 芯片数合计加权。只有百分比、缺少样本数的多个结果不能加权，会显示无法计算。

管理界面的**良率明细、数据文件、不良分类**各列表头均有关键字输入框，右键列头可搜索、勾选需要的值。不同列条件及输入 / 勾选条件同时生效；有筛选的表头以浅蓝色提示，清空关键字并清除此列勾选筛选即可恢复。各表筛选独立，只改变当前表格显示；趋势与报告仍按页头统计口径和批次 / 晶圆范围计算。切换产品清除三个表的筛选，切换统计口径清除良率与分类表的筛选。

逐颗复测和跨温匹配在全部选定数据内完成后再按期间归档。阶段良率使用所选首测 / 末次记录的测试时间；综合按已测必测步骤中最晚的时间归属（未测步骤仍保留缺温计数），不会因跨月而拆散同一颗芯片。已测必测步骤只要有时间缺失，该颗综合结果即归入“未指定时间”。旧目录也可在“编辑登记 / 指定值”补填测试时间，然后重算。分类占比分母为对应期间有效 SBIN 的芯片数，不对各晶圆占比取简单平均。

**删除产品**移除产品定义、数据登记与统计摘要；数据文件页**删除登记（保留原文件）**支持多选。两者均需确认，且只改本机产品目录，原 CSV / STDF 文件不移动、不删除。删除登记后先清空旧统计再重算，即使取消重算也不会继续显示已删除文件的结果。

产品目录位于当前 Windows 用户的本地应用数据目录下 `SemiconductorCsvAnalyzer/ProductLibrary/catalog.json`；仅保存路径、配置和统计摘要，不保存原始测量矩阵。每次替换目录时保留上一份 `catalog.json.bak`，建议备份该目录。多个程序同时编辑时会阻止旧目录覆盖新目录；目录损坏会保留原内容，并仍允许使用独立分析器。

## 02 · 打开 CSV 与 STDF

### CSV

在设置中加载或编辑 `config.ini`，填写测项名称、上下限、单位、数据起始行，以及 SN、X、Y、Site、Wafer、SBIN、HBIN 等列。行号和列号从 1 开始；可选字段使用 0 表示未配置。WaferColumn 为 0 时按文件名区分晶圆。

也可使用 **设置 → CSV 格式 → 选择 CSV → 开始识别**，核对采样预览和可编辑 INI 后选择“INI 另存为”，或“采用此配置”再点击“应用分析配置并重算”。仅打开设置或选择文件不会运行识别；识别、预览和另存为均不改变当前分析配置。识别支持多行测项名称、常见身份列、阈值和单位行，并提示不确定项。

多行名称使用 `TestItemRows=1,2`；可用 `TestItemColumns=8,9,12` 明确指定测项列。空列表继续使用旧版 `TestItemRow` 和 `TestItemStartColumn`。上层空白名称向右延续，纵向合并保留本列显式名称，整列无显式名称的空白列不创建项目。`SkipRepeatedHeaders=true` 跳过同格式的重复名称与定义块，不把表头计入芯片或异常值。引号内换行也可读取，此时 INI 行号按逻辑 CSV 记录计数。自动采样最多 256 条记录 / 2 MB 文本；无标签限值只作建议，不以测量范围生成规格。不同布局的分块应拆开后分别配置，或先统一表头。更详细的例子见源码仓库中的 `Docs/CSVFormats.md`。

CSV 的编码、分隔符与引号规则也由配置控制。软件导出的整合 CSV 自带测项定义和晶圆信息，可直接重新打开。配置重读全部成功后才替换当前数据；失败时保留之前的数据。

普通 CSV 未指定 `SerialNumberColumn`（或设为 0）、序列号存在空值，或任意晶圆间出现重复序列号时，软件在导入后按记录顺序统一生成 1～N，替代用于浏览的 SerialNumber，并弹窗提示。追加导入后也检查合并结果。原文件不改写，原 SN 仍用于无完整坐标时的复测识别；导出的整合 CSV 会保存这层对应关系。STDF 自带的 PART_ID 也检查空值和重复，不使用 CSV 的序列号列配置。

### STDF 与 93k

支持 STDF V4 的 `.std`、`.stdf`、`.std.gz`、`.stdf.gz`，读取 PTR、MPR、FTR，支持 IEEE 大端与小端。V3、VAX 或 STR 扫描等不支持的记录会明确提示，避免静默遗漏测量项。

- **普通模式**：使用常规测量记录中的测试名。
- **93k 模式**：优先按测试序号、类型与 Head/Site 匹配 TSR 的完整 TEST_NAM；文件末尾的 TSR 同样生效。没有适用 TSR 名称时回退到常规名称。
- MPR 多结果拆分成分项；FTR 功能测试以 0=Pass、1=Fail 表示，不是电气单位。
- 同一测试使用不同限值或单位时拆成规则分项；缺测、无效与不适用数据分别保留。
- 坐标、Site、晶圆、BIN、产品、程序和批次按文件记录读取。没有完整坐标时仍可统计，但不能绘制该颗芯片的 Map。

每个导入来源保留当时选择的 STDF 模式，修改配置重读时继续使用。STDF 的 HBIN 良品归类仍由当前 INI 设置决定。导出提供整合 CSV 与 XLSX，不生成新的二进制 STDF。

### STDF Lot Information

分析器顶部点击 **Lot Info**，左侧列出当前打开或追加导入的 STDF 源文件（含 `.gz`），单击文件即可切换。CSV 不进入该列表，同一路径只列一次。追加导入或重新打开数据时，已打开的信息窗口同步更新文件列表。

**Lot / 批次信息**展示 MIR / MRR 中的原始字段，包括批次、产品、程序及版本、机台、操作员、测试阶段、温度、设置与起止时间等。**Wafer / 晶圆信息**按每次 WIR / WRR 展示晶圆号、Head / Site Group、起止时间、测试 / 良品 / 复测数量、Fab 与框架 ID 等。相同片号的不同测试轮次分别列出；结束记录修正晶圆名称时仍保留起始记录原文。

空白表示原文件未提供，日期按本机时区显示。这里是源文件记录，不受管理界面的手动批次 / 晶圆覆盖、复测显示模式、HBIN 归类或阈值模拟影响，文件内汇总数量也不是软件重算结果。FT 文件没有晶圆记录时，只显示批次信息。

“复制全部信息”复制当前文件的批次及全部晶圆字段；“重新读取”清除该文件缓存并再次读取。文件切换在后台进行，只保留少量基本信息，不重新加载测量矩阵，也不触发主表与图表重绘。文件被移动或损坏时显示读取失败，不沿用上一个文件的内容。

### 批量追加导入

独立分析器首次点击“打开文件”即可多选，随后弹出与追加导入相同的选项，并可调整文件顺序。首个文件作为基础；选择同 wafer 时，首个文件须仅含一片晶圆，其余文件合并到该片。阈值可保留首个文件，或按后续文件覆盖。空载时点击“追加导入”也可进入首次打开流程。整批成功后才替换当前数据，失败或取消保留之前的数据。

点击“追加导入”，在文件选择框按 Ctrl / Shift 多选 CSV、STDF 或 STDF.gz。导入窗口显示全部文件，可通过“上移 / 下移”调整顺序；文件按列表从上到下追加，后面的记录视为较新的复测。选择同 wafer 时，每个追加文件必须仅包含一片晶圆，并统一合并到所选已有晶圆；不同 wafer 保留各文件的晶圆，重名晶圆自动区分。

测项匹配方式及新 / 旧阈值选项统一应用于本批文件。采用新阈值时，以最后一个匹配到该测项的文件为准；采用旧阈值时保留已有项的阈值。STDF 模式只询问一次并统一应用于本批 STDF 文件；CSV 仍使用当前配置。导入完成后统一重算并刷新；任一文件失败会提示文件名，整批均不加入当前数据。序列号重编提示在完成后统一显示。

## 03 · 主列表、筛选与关注

主列表默认按“测试项 × Site”分行。Combine Site 合并 Site 后，每个测试项显示一行。点击某项后，图表与原始值入口使用该项；原始值表按需读取该测项原文。

- **列头关键字**：输入关键字执行包含匹配，不区分大小写。
- **右键勾选筛选**：右键数据列表头，搜索候选值、勾选并应用。不同列的条件同时满足才显示，也与关键字条件叠加。
- 搜索只缩小候选列表；“全选 / 取消搜索结果”仅影响搜索命中的值。取消弹窗不应用，清除此列筛选恢复该列全部值。
- **关注**：同一测试项各 Site 共用关注状态。双击“关注”表头全选当前筛选内的测试项，再双击取消全选；被筛选隐藏的项不变。关注项进入 XLSX 的第四张工作表；关注不会改变统计或筛选。
- 拖动表头可调整宽度和顺序，点击表头排序，按住 Shift 可多列排序。布局自动记忆。

主表的复制操作包含当前筛选、排序后的全部行，不限于屏幕内的行；列按固定统计字段顺序输出，不随拖动表头改变。报表中的全部测项统计按导出条件重算，不受主列表的文本 / 勾选筛选影响。重新打开新数据会清除原关注与勾选筛选；追加匹配的测项保留关注。

### Run 与 Value

在原始值、复制旁的 **Run** 输入芯片序列号后按回车，或使用上下箭头按导入顺序切换记录；支持数字及文本序列号。输入不存在的序列号会保留原选择，状态栏提示当前记录的顺序、Wafer 与 Site。

在“设置 → 界面与习惯 → Run 选取方式”中可改为 **晶圆 + X/Y 坐标**，点击“保存界面设置”立即生效并记忆。晶圆使用输入框与上下按钮切换；输入 X/Y 后按回车定位该坐标的末次原始记录，支持负坐标。坐标旁的上下按钮按导入顺序浏览当前晶圆有完整坐标的各条记录，包含首测和各次复测；切换晶圆优先保留 XY，若不存在则选择该晶圆首个坐标的末次记录。找不到晶圆或坐标时保留原选择，没有完整坐标的文件使用序列号模式。

**Value** 列位于 Mean 后，显示该条原始记录的测量值。分 Site 时仅对应 Site 行显示数值；其他 Site、缺测、不适用和无效值显示“–”。Combine Site 后每项一行显示该记录数值。Run 始终浏览原始记录，不随首测 / 复测统计口径删除记录，也不把其他复测的值补到当前记录中。切换 Run 不重新计算均值、良率或绘制分布图。复制主表包含当前 Run 的 Value；XLSX 报告仍按导出条件计算汇总统计。

Value 低于 LSL 或高于 USL 时使用粉红色单元格底色，文字保持正常深色；恰好等于上下限仍通过，单边限值只判断已配置的一侧。InSpec% 单元格按固定 0～100% 色标渐变：低良率红色、中间黄色、高良率绿色；没有有效测量值时不着色。

## 04 · 统计与复测口径

Count 表示有效有限数值的数量，Fails 为超出原始 LSL 或 USL 的有效样品数（边界值通过，每条记录最多计一次），Max / Min 为有效测量值的最大 / 最小值，无有效值显示“–”。Fails 为 0 时底色绿色，大于 0 时为淡粉色；其统计范围沿用当前晶圆、Site 和复测口径。Mean 为均值，Median 为中位数，σ 为总体标准差，InSpec% 为满足原始上下限的有效数值比例。异常值不作为 0 参与数值统计；Error（旧名称 Eorr）记录空值、非数值等异常，未进行或不适用的测试不会冒充有效测量。Test Num 为测试序号，Test Item 为测试名称，Unit 为单位；复制和 XLSX 报告包含新增统计列。

Site σ 仅在 Combine Site 下显示，为各 Site 良率的总体标准差，各 Site 等权，单位是百分点；分 Site 时显示“–”。Robust Mean / Robust Sigma 是按设置中均值 ± Nσ 进行一次离群点剔除后的统计，默认 N=6，不迭代剔除，也不修改原始良率或图表。

**Combine Site / Combine Wafer** 可以独立切换，默认均关闭。两者关闭时，每个测项按“晶圆 × Site”分行；只合并 Site 时每个晶圆一行，只合并 Wafer 时每个 Site 一行，两者开启时每个测项一行。没有有效值的组合仍显示 Count=0。Wafer 列支持筛选与复制；选中行的统计、直方图、散点图和原始值表均使用该行的晶圆与 Site 范围。Site σ 在未合并 Wafer 时只比较当前晶圆的各 Site。Run 的 Value 只显示在匹配当前记录晶圆与 Site 的行中。

主列表提供四种重复测试规则：

1. **首测与复测均保留**：全部测试记录参与统计。
2. **只保留首测**：对每颗芯片、每个测项保留最早一次。
3. **复测覆盖首测**：对每颗芯片、每个测项保留最后一次；部分复测未包含的项沿用已有测项。
4. **只保留复测**：对每颗芯片、每个测项去掉首次，保留后续全部复测；仅测一次的项不计入。部分复测中新出现的测项仍视为该项首次，直到再次测量才计入。异常值也占一次测试。

芯片优先按 Wafer + 完整 X/Y 区分；坐标不完整时按 SN，再无 SN 时视为独立记录。同坐标不同晶圆互不覆盖。选择只改变本次计算口径，加载的原始记录继续保留。

XLSX 报告选择只保留复测时，BIN Map 与统计仅包含有复测测项的芯片，采用整条末次记录。独立的 BIN / Wafer Table 仍提供首 / 末条记录两种口径。

BIN 统计使用整颗芯片首 / 末条记录；这是与逐测项复测不同的口径。良率预测每颗芯片只计一次，因此提供首测与复测覆盖首测两种模式。

## 05 · 图表与晶圆 Map

### 直方图与散点图

两种图表右上角的复制图标可将当前图表复制为 **PNG**，包含坐标、图例及当前散点缩放和绿色标记，不含工具栏按钮；同时提供兼容 Excel / Paint 的图片格式。PNG 像素尺寸等于图表当前逻辑尺寸乘以 Windows 显示缩放。剪贴板被占用时提示重试。

直方图可切换固定等宽、规格区间、中位数中心。参考线显示原始上下限、均值及 σ 范围，具体开关在设置中调整。散点图支持缩放和平移；列表滚动期间不会反复重绘既有图表。

直方图的柱形、文字和坐标直接绘制，不生成整张图的静态图片。散点图将视野内的点绘制到一个可复用的像素图层，坐标、文字和游标独立绘制，不再叠加整图快照。移动游标只更新游标图层；调整窗口、分隔条尺寸，以及滚轮缩放、平移和重置，都按实际尺寸与真实测量点重绘，不拉伸旧截图代替数据，也不减少参与统计的样品。点图层设有像素总量限制，窗口大幅缩小后会缩减缓冲；清空数据或卸载图表时释放缓冲引用。切换测项期间保留上一组图表并显示计算提示，最新结果就绪后一起替换。XLSX 报告按导出分辨率重新绘制，不使用屏幕截图。

散点图标题旁可切换 **按 SN / 按 Site / 按晶圆**。SN 数字按数值大小排序，文字 SN 按文字排序；按 Site 时先比较 Site，再比较 SN；按晶圆时使用晶圆在原始数据中首次出现的顺序，同晶圆按 SN 排序。相同排序键保留原始记录先后。按 SN 时横轴显示排序后的样本序号，排序不修改原始记录、统计、复测口径或 Run 选择。单个晶圆或 Site 范围内，排序只作用于该范围。

按 Site / 晶圆时，横轴改为对应的 Site / 晶圆名称，各组正常测量点交替使用深蓝与浅蓝，组间用浅灰色竖线分隔。各组宽度与样本数成正比，长名称按可用宽度自动缩小；缩放、平移后名称仍显示在当前可见组内。超限点继续显示红色。图内悬浮信息包含完整的组名，报告中的散点图沿用同样样式。按 SN 时恢复样本序号横轴和普通蓝色点。

**散点标记**：在图内按下右键即可拖出半透明矩形，不再等待；松开右键标绿框内散点，多次框选会累积。按 SN 时使用深绿，按 Site / 晶圆时各组交替使用深绿和浅绿。标记按同一次原始测试记录保存，跨测试项、排序和筛选保留；同一芯片的其他复测记录不会自动标绿，除非也在选框内。超限点被标记后显示绿色，清空后恢复红色，统计与限值判断不受影响。右上角 **清空标记** 一次清除所有测试项的标记，并取消未完成的选框；加载新数据也会清空。左键平移，仅双击左键重置缩放；短按右键不再重置，Esc 取消选框。标记仅在当前窗口内保存，不写回源文件或导出报告。

框选按点中心是否落入矩形判断，采用当前缩放与纵轴范围。拖动选框只更新叠加层，松开后才重绘点颜色，继续使用原有位图和可复用缓冲。**左键拖动仍为平移**，滚轮缩放，仅双击左键重置；右键只用于框选，Esc 取消未完成的框选。

散点排序按钮右侧的 **锁定纵轴** 保留当前显示的纵轴范围，包括已经缩放的范围，方便切换测项对比。锁定后滚轮、拖拽和双击重置只调整横轴；切换排序、晶圆或 Site、调整窗口大小均保留纵轴。未选择测项时勾选，会在首个测项加载后锁定。取消勾选恢复当前测项的自动纵轴范围；直方图不受影响，报告图表仍按各测项自动设置范围。

### SBIN / HBIN Map

通过左侧晶圆列表切换 Wafer，右侧图例对应颜色及 BIN。可开启 / 关闭 Site 加粗边框与 die 内的 BIN 数字。悬停可查看晶圆、坐标、Site、SN 及 BIN 信息。Map 在同晶圆、同坐标上显示最新记录，不把重复记录画成多个格子。

图例的 **显示** 列默认全部勾选，表示显示该 BIN 的原色；取消勾选后该 BIN 的 die 显示为灰色（#C0C0C0）。点击 **显示** 列头切换当前晶圆图例的全选 / 取消全选；部分勾选时先全选。数量、占比、BIN 数字和悬浮信息不变，重新勾选恢复原色。选择按 BIN 在同一 Map 窗口的各晶圆间保留；重新打开 Map 默认全选。批量切换只重建一次颜色缓存，坐标与 Site 边界继续复用。P/F 和热力图不使用此开关。

SBIN 1 / HBIN 1 使用绿色，其余 BIN 使用 50 种避开灰色和绿色系的颜色。按全体晶圆、全部原始测试记录中的 BIN 排序分配，同一数据内切换晶圆或报告复测口径不会改变 BIN 原色；50 个 BIN 可使用不同颜色，即使 BIN 编号不连续。报告中的 Map、图例和 BIN 统计颜色一致。非 1 的 BIN 超过 50 个时循环使用配色；P/F 的绿 / 红及热力图的蓝 / 绿 / 红保持原含义。

### CP / FT 复测识别

在 **设置 → CP / FT** 切换模式，点击“应用分析配置并重算”生效，模式与 Test Num 列表保存在 INI 的 `[RetestIdentity]` 中。未配置时默认为 CP，沿用同晶圆优先完整 X/Y、无完整坐标时原序列号的判断。

FT 模式按 eFuse / OTP 芯片 UUID 识别同一芯片，覆盖原有晶圆、坐标与序列号条件，跨 Site 或晶圆标签也能识别复测。在“配置 / 预览芯片 UUID…”窗口填写 Test Num，可预览前 100 条记录。单个测项直接作为 UUID；多个按填写顺序直接拼接，例如 `UuidTestNumbers=101,102`，读到 `E8`、`A9`，UUID 为 `E8A9`。只去除首尾空格，保留大小写和前导零，不转换进制，也不添加分隔符；请选用长度和格式稳定的芯片编码字段。

任一必需值未测、空白、标记为未测 / 不适用或 NaN / Infinity 时，该条记录独立保留，不回退到 SN / XY；导入或应用设置后提示缺失数量。找不到 Test Num 时同时列出编号，重复 Test Num 定义会报错以避免读错项目。UUID 只作为派生身份，不改写源文件、测量值或 Run 序列号。切回 CP 恢复原规则。四种复测口径、BIN 统计与良率预测共用这一身份；晶圆表内占比仍按各晶圆分别统计。

FT 整合 CSV 使用第 4 版格式保存派生 UUID 与其 Test Num 顺序，保证按测项保留的部分复测记录重新导入后仍能识别同一芯片；旧版整合 CSV 仍可读取。修改 UUID Test Num 顺序后会按新顺序重新读取，不复用旧方案的身份。

### P/F 与热力图

P/F Map 对当前测项显示测量结果，也可切换为热力图。均值为绿色，低于均值渐蓝，高于均值渐红；默认范围为均值 ±6σ，可输入正数 N，也可切换最小值 / 均值 / 最大值模式。范围外的值固定为端点颜色，不删除数据；无效值显示灰色，σ 为 0 的有效值为绿色。

选择“自定义蓝 / 绿 / 红色标”，分别输入三个数值后点击“应用自定义色标”。需满足 **蓝标 < 绿标 < 红标** 且均为有限数字；允许负数、小数和科学计数法。绿标可以与实际均值不同，蓝→绿和绿→红两段分别渐变，超出范围固定为蓝 / 红色。输入无效时保留当前图像和已应用范围。可随时切回均值 ± Nσ 或最小值 / 均值 / 最大值；自定义色标在当前窗口切换晶圆时保留。

多晶圆使用当前测项、当前 Site 范围内的所有有效测量值共同计算均值、σ 和色标。每个测量值等权，不是各晶圆均值的简单平均；切换晶圆时色标一致。Combine Site 时使用全部 Site。

## 06 · BIN Table 与 Wafer Table

**BIN Table** 包含 SBIN 明细、HBIN 明细、SBIN 分类汇总，下方为 SBIN 各 Site 占比。分类名称在每行正常显示，同分类使用相同浅色底色。首测 / 复测覆盖首测同时作用于各表。

Site 表每格为“该 Site 中此 SBIN 数量 ÷ 该 Site 有效 SBIN 总数”，有数据的 Site 一列约为 100%（显示有舍入）。空 Site 单独显示，无有效 BIN 时显示“–”。复制全部会包含分类、表名与列头。

**Wafer Table** 包含 SBIN、HBIN 和 SBIN 分类三个表，每个晶圆一列。可以切换数量 / 占比、首测 / 复测覆盖首测；拖动两条分隔条调整三表宽度，列宽也可调整并自动记忆。

点击 **不良分类趋势** 打开晶圆分类占比折线图，下方表格与折线使用相同的晶圆顺序、分类颜色和百分比。左侧可以逐项勾选分类，也可以全选或清空；默认显示全部分类，仅查看不良时可取消良品分类。隐藏分类不会改变占比分母。复测模式跟随 Wafer Table 的首测 / 复测覆盖首测选择，趋势图始终显示占比，不受原表数量显示模式影响。纵轴采用较密的刻度并按图表高度调整间距；晶圆较多时，下方表格横向滚动会带动折线同步移动。无有效 SBIN 的晶圆显示“–”，折线在此留空。

SBIN 及分类的占比分母为当前范围内有效 SBIN 数；HBIN 的分母为有效 HBIN 数，不把缺失 BIN 计入分母。

分类在 INI 定义，名称和数量自定，一个 SBIN 只能归入一个分类：

```ini
[SBinCategories]
坏点=1,2,3
坏线=4,5,6
```

未配置的有效 SBIN 归入“未分类”；`01`、`1.0` 与 `1` 视为同一个数值 BIN。上面仅为格式示例，请按实际业务定义分类。

## 07 · 追加导入与数据导出

已有数据时使用追加导入，选择同 / 不同 Wafer，按测试序号 / 名称匹配，以及采用新 / 旧文件阈值。同 Wafer 重复记录保留，统计由当前复测口径决定，Map 使用最新值。不同 Wafer 分别统计坐标。

未匹配项目作为新测项保留；空键、重复匹配键或单位冲突会提示。MPR 多分项可能共享测试序号，此时建议按明确且唯一的名称匹配。CSV 与 STDF 可混合导入。

导出数据时独立选择晶圆、四种记录保留规则，以及是否剔除离群点。剔除先合并所选晶圆与 Site，逐测项计算均值和总体 σ，保留均值 ± Nσ 内的数值（含边界）。仅将超限测项置为缺测，保留同条记录其他测项、芯片信息及原始 BIN，不删除整颗芯片。

导出选择不修改主列表或源文件；异常原文继续保留，软件导出的整合 CSV 可再次直接打开。

## 08 · XLSX 报告

报告选项包括晶圆、重复记录方式、离群点处理、Combine Site / Combine Wafer、直方图模式、显示 BIN 数字与 Site 边框。两个合并开关初始沿用主窗口，Testitem 工作表按所选组合分行并包含 Wafer 列。关注测项图表仍合并所选晶圆和 Site，散点图模式可选按 SN / Site / 晶圆，初始沿用主窗口，另可选择 Zoom limit（不勾选为 Zoom all）。直方图与散点排序选择会同步主窗口；即使取消导出，也保留新选择的模式。

报告中的直方图与散点图分别沿用界面当前绘图区尺寸（不含工具栏），PNG 分辨率随 Windows 显示缩放；隐藏图表使用最近显示尺寸。图片按该逻辑尺寸嵌入 Excel，按图表高度留出空间，避免遮挡后续图表与测项。报告按所选数据重新绘制完整图表，不沿用手动平移/缩放、纵轴锁定或绿色标记。

报告固定包含四张工作表：

1. **Testitem Yield**：所选范围的全部测项统计，带数字格式、筛选及冻结表头；不是全部芯片原始测量矩阵。
2. **SBIN Map**：按晶圆排列 Map、图例、SBIN 统计及分类汇总。
3. **HBIN Map**：按晶圆排列 Map、图例与 HBIN 统计。
4. **关注测项**：每个关注项依次生成两行统计表、直方图、散点图；无关注项时显示提示。

报告选“只保留首测”时，Map 与 BIN 统计用首条芯片记录；另外两种模式均使用末条。无完整坐标的芯片计入统计并列出数量，但不生成虚构坐标。

统计单元格为可编辑数字；图表为嵌入图片，不随 Excel 单元格编辑重新计算。生成不依赖安装 Excel，导出过程显示处理动画，完成后再打开目标文件。

## 09 · 阈值模拟与良率预测

### 先确认身份和有效测试项

原始芯片是否为良品由 HBIN 分类决定，Pass 与 PartialPass 两组不可重叠，其余 HBIN（含空值）为不良。示例：

```ini
[HBINClassification]
PassHBins=1
PartialPassHBins=2,3

[PredictionContext]
Product=产品A
Program=程序V1
Lot=批次A
```

上述身份默认值仅适用于确实属于同产品、程序与批次的数据；混合数据应配置实际身份列或使用 STDF 身份记录。旧 Pass/Fail 列配置不再参与判断。

1. 选择 Pass 或 Pass + PartialPass 作为目标，选择首测 / 复测覆盖首测。
2. 检查有效项建议、debug / 读值项候选和“良品超限”冲突。全通过的项目不会自动关闭，建议需要人工确认。
3. 核对阶段；同阶段可使用相同数字，阶段用于匹配缺测前段值，不假设缺测连续。
4. 点击“确认有效项 / 建立基准”，查看基准与原始 HBIN 判定差异。
5. 调整模拟 LSL / USL 或取消“模拟启用”，停止输入后后台重算。可恢复原规则、保存与载入方案。

原始测量值、原始阈值与主表不被模拟修改。有效项或阶段变更后需要重新确认；方案只适用于匹配的测项及配置。

### 如何理解结果

整颗芯片按全部必要测项联合判断：任一有效项失败即可确认不良；必要项全部通过才确认良品；其余区分缺测、不适用和无效。不能把各项不良率简单相加。

测试项表的“测试数量 / 原良率 / 预测良率”仅统计有效实测值在原始 / 模拟阈值下的单项结果，缺测不进入分母，关闭项目不显示虚假的 100%。上方整颗芯片联合良率与缺测概率是另外的口径。

缺测预测按同产品、兼容程序，优先同批次且前段值接近的参考芯片，计算“缺测集合全部通过”的联合经验概率。参考包含不良品，不仅挑完整测试或最终良品，也不相乘各项边际通过率。样本不足、未知身份、无前段依据或参考仍有未知时显示无法估计；超出旧阈值支持范围时标记外推。

预计良品数等于确认良品数加上已估计芯片概率之和。预测未覆盖全部芯片时，查看覆盖数量、无法估计数及总体范围；不要把“已覆盖部分概率预计良率”当作全量确定结果。

模拟 Map 中：绿色为确认良品，蓝色为确认恢复，红色为新增不良，深红色为确认不良，橙色为待预测，灰色为无法估计。概率即使为 100%，仍显示待预测，不冒充确认良品。

> 预测用于分析阈值方案，不代表未经生产验证即可采用的新测试规范。

## 10 · 设置与日常习惯

在“界面与习惯”调整紧凑表格、列头关键字筛选框、交替行底色，以及 STDF 模式默认选项。保存界面设置只更新显示与习惯，不重新解析数据；打开 STDF 时仍会弹出模式确认。

隐藏列头输入框时会清除关键字条件，避免不可见的筛选；右键勾选条件保留，仍可通过浅蓝色表头查看、修改或清除。

“统计与绘图”中的离群点定义只影响 Robust Mean / Robust Sigma；同页可调整直方图默认模式、分箱数量，以及 LSL / USL / 均值 / ±3σ 参考线。“INI 配置”可直接编辑完整文本，常用选项会与 INI 同步。修改分析配置使用“应用分析配置并重算”，导出 config.ini 可供其他数据重复使用。

“最近文件”提供最近配置和 CSV / STDF 的快速入口。最近数据使用当前生效配置打开并替换当前数据；尚未应用的编辑不参与读取。

窗口大小、分隔比例、列宽 / 顺序及排序自动记忆。尽量通过分隔条为表格和图表分配空间；紧凑模式适合同时查看较多行，常规模式适合阅读较长内容。

## 11 · 常见情况

- **测试名称过短**：STDF 可重新打开并选择 93k 模式，使用 TSR 完整名称；仍缺少名称时核对源文件是否提供对应 TSR。
- **Map 没有部分芯片**：检查 X/Y 是否完整。无坐标记录仍参与统计，软件不会人为补坐标。
- **不同窗口良率不同**：先核对 Wafer、Site、复测方式、上下限、缺测及 BIN 分母；单项通过率与整颗芯片 HBIN 良率并非同一指标。
- **预测无法估计**：查看逐芯片依据及缺测集合覆盖，核对产品 / 程序身份、兼容关系与参考样本。未知不会被自动当作通过。
- **导出文件正在使用**：先关闭 Excel / WPS 中的同名目标文件，再重试导出；原始数据仍在程序中。
- **内存未立即下降**：测量数组、打开的图表及原文快照各有生命周期；关闭窗口后回收会在空闲时安排，任务管理器工作集可能延迟回落。大文件处理时先等待当前操作结束。

可以从“关于 → 详细说明”随时打开本手册，直接阅读并通过目录跳转。

### 处理取消、内存与配置保存

导入、追加、主表重算及导出期间，窗口底部显示“取消处理”。点击后会在安全点停止，保留上一次有效数据；请求关闭窗口会先取消当前处理，结束后关闭。XLSX 正在压缩保存时需要等待该步骤结束，再删除临时输出；取消或失败不会以半成品覆盖原报告。应用设置时可在设置窗口点击“取消处理”，配置开始写入后则先完成这一小段保存。

原始值窗口会独立保留它正在使用的原文快照。替换数据或关闭最后一个使用者时关闭对应临时文件，不再每次操作都连续强制压缩内存。运行时仍可能保留可复用的堆空间，因此任务管理器数字不一定立即下降。

默认配置及设置保存到当前用户的 `%LOCALAPPDATA%\SemiconductorCsvAnalyzer` 目录；初次使用自动读取旧程序目录中的配置副本，已有用户配置不会被覆盖。保存先写临时文件并验证，再替换正式文件，上一份保留为 `.bak`；程序目录无需写权限。主窗口启动时默认配置损坏会尝试上一份备份。手动导出的 INI 使用同样的安全替换方式。

- **良率预测**：最多匹配缺测前最近 8 项；优先同批次；不删除参考中的未知结果。

- **散点图范围**：锁定纵轴旁选择 Zoom limit 或 Zoom all。Zoom limit 的纵轴为 `LSL − 0.5 × (USL − LSL)` 至 `USL + 0.5 × (USL − LSL)`；缺少有效双侧限值时回退到全部数据。Zoom all 显示所有有效数值；主动切换范围时重新捕获锁定范围。滚轮缩放范围扩展为 0.001～100,000 倍；仅双击左键恢复当前范围模式。

- **数据筛选**：顶部文件工具栏的 XLSX 报告右侧点击漏斗图标“数据筛选”。窗口打开时可继续操作主窗口，只列出已关注项；返回筛选窗口时更新关注列表。按显示单位填写“小于等于”和“大于等于”：`≤ 1、≥ 3` 选两侧，`≤ 3、≥ 1` 选中间；边界包含，留空表示单侧不限。多个测项可选交集（全部满足）或并集（任一满足），缺测/无效值不满足对应条件。保留全部记录模式逐条匹配；首测/末测模式按复测选值匹配芯片，支持分段测试；仅复测模式使用末次复测值匹配并保留芯片历史。点击“应用”后留在窗口继续编辑，“关闭”不提交尚未应用的修改；取消关注后的条件在下次应用时移除。主列表、Map、BIN/Wafer Table、良率预测及导出统一使用筛选后的样品。“取消数据筛选”恢复全部数据，打开新文件或追加导入会清除筛选。

- **合并打开失败**：管理界面会弹出文件路径与失败原因，并将异常明细写入 `%LocalAppData%\SemiconductorCsvAnalyzer\Logs`。配置不兼容、单位冲突、文件缺失或损坏等失败不会覆盖已有分析数据；原文件与登记信息保持不变。

- **Fail / 复测良品芯片 XLSX**：在“导出数据”勾选“Fail / 复测良品芯片”，晶圆、复测保留方式和离群点选项沿用数据导出。固定生成“Fail 芯片”和“复测良品芯片”两个工作表。Fail 按末次记录 HBIN 分类，仅配置的 Pass 为良品，PartialPass 仍进入 Fail；复测良品为有多次测试记录且末次 HBIN 为 Pass 的全部芯片，包括首测失败后转良、首测及复测均为良品。分类看芯片末次 HBIN，实际输出的记录和测项仍按所选复测保留方式处理。CP 按晶圆/XY（缺坐标时使用原 SN），FT 按批次/UUID 分组。若一类为空，仍保留对应工作表的表头和元数据；两类均为空时提示且不覆盖目标文件。

  两个工作表删除原先顶部四行说明；第一行直接显示组别、身份字段及测试项名称，只冻结第一行和第一列“组别”，其余元数据行随滚动移出视野。测试编号、单位、LSL、USL、SBIN、HBIN 保留在第 2～7 行，记录从第 8 行开始。每颗芯片的独立标题、折叠层级和空行均移除，芯片的首测与复测分行连续排列。测项通过为绿色、超限为红色；相邻芯片交替采用深浅两套红绿底色，同一芯片的所有记录使用同一套深浅度，身份列也同步交替。无效原文仍为黄色，未测/不适用/剔除值为灰色，并跟随芯片深浅度。

  Fail 表开头仍附一颗良品参考：只用所选 Pass 芯片的逐项末次保留值计算均值/σ，优先实测项目覆盖最多，再选各项按 σ 归一化后均方距离最小的芯片，平手按源顺序。没有可用参考时仅输出 Fail 记录并在状态栏提示。若参考芯片自身也是复测良品，它还会在第二张表正常列出；状态栏的总记录数包含两张表实际写入的记录（含参考）。原始数据不变；XLSX 继续逐行写入，避免整份工作簿对象常驻内存。

- **SBIN 释义**：在设置“SBIN 释义”页逐行填写 `2=开路`、`3=短路`，应用后写入 INI 的 `[SBinDescriptions]`。BIN Table 的 SBIN 明细与各 Site、Wafer Table 的各 Wafer 均显示释义，并加入复制内容和 XLSX 报告。释义不影响原有分类与占比；未配置则留空，数值写法 `02`、`2.0` 与 `2` 共用释义，重复定义会提示错误。

- **图表布局**：拖动直方图/散点图之间的分隔条到顶部，仅显示散点图；到底部，仅显示直方图。图表标题右侧的“双图 / 直方 / 散点”可直接切换；双击分隔条或选“双图”恢复，保留原来的图表数据和最近双图比例。

- **共享读取与内存**：数据文件使用只读共享方式打开，允许 WPS / Excel 等程序同时打开文件，但无法绕过其他程序的独占锁。读取期间检测到文件被修改会提示重新导入，建议先保存编辑结果。CSV 数值保留 double；STDF 列使用无损 float，遇到无法精确表示的数值自动转为 double。有效数值不足源记录数 60% 的列自动压缩，并保留原行号；缺测和无效原文仍可查看。两种入口均使用工作站 GC；首次窗口就绪、空闲至少 5 秒且托管堆不超过 32 MiB 时，仅执行一次紧凑回收。后续回收继续避开交互并限频，不强制清空进程工作集。

- **连续打开文件**：整合 CSV 使用分块读取，减少宽表产生的临时分配。替换文件、关闭 Map 等操作会请求空闲回收；60 秒冷却期内保留请求，到期且交互空闲时再执行后台回收。任务管理器中的驻留内存还包括 .NET / WPF 的缓存与保留页，不要求每次关闭文件后立即回到冷启动数值。
